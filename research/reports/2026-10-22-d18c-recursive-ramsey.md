The connected degree18 branch now has an exact residual-state theorem and a
deterministic dynamic-programming prototype. The result replaces separate
one-step interface tests with a recurrence that preserves arbitrary mixed
attachments and recursively applies smaller Ramsey bounds to overlapping
supports. It does not change a numerical Ramsey bound or exclude the branch.

The [proof note](../n43/d18/c/recursive_ramsey.md) contains six separately
anchored claims, all **ready for independent review**:

* `claim-d18c-residual-derivative`: a full vertex row gives an exact smaller
  state by inheriting each homogeneous obligation and decrementing it on the
  row's neighbor or nonneighbor support; linear costs transport by equality.
* `claim-d18c-residual-congruence`: dominated obligations can be removed, and
  equal normalized states have exactly the same labelled future completions,
  even when their fully assigned processed histories differ.
* `claim-d18c-recursive-capacity`: each positive/negative support intersection
  receives a valid smaller-Ramsey capacity and associated row-degree interval;
  bound entries themselves are generated by the additive Ramsey recurrence.
* `claim-d18c-completion-dp`: the sum over every compatible row computes the
  exact labelled completion count, with multiplicity when distinct rows share
  a child, and a finite acyclic recurrence record with explicit replay contracts.
* `claim-d18c-unified-interface`: the fixed connected degree18 neighborhood
  initializes this recurrence exactly. Its residual obligations recover row,
  edge, triangle, independent-pair/triple/four, and mixed-cell restrictions.
  A transversal core uses the same operator and recovers the deletion envelope.
* `claim-d18c-polynomial-obligation-kernel`: a surviving `K_p/I_q` completion
  history retains at most `sum_(t=0..p-2) binom(h,t)` positive and the dual
  number of negative obligations. After eliminating the d18 neighborhood,
  each colour has at most988 masks of width24, with exact future semantics.

The new state congruence permits arbitrary fully assigned future rows, while the
existing [boundary profiles](../foundations/boundary_profiles.md)
restrict their context algebra to uniform interior joins. The new theorem
retains overlapping support masks. Each reachable fixed-parameter history has
a polynomial-size representation; the number of possible states can still be
exponential. It does not claim bounded width or a guaranteed speed improvement. The existing
[attachment template](../../docs/general_theorems/ramsey_attachment_calculus.md)
supplies the underlying mixed-set criterion; the additional content here is
the derivative, history quotient, polynomial-size kernel, complete counting
recurrence, and executable branch specialization. No novelty or
literature-priority claim is made.

The [prototype](../n43/d18/c/recursive_ramsey.py) uses immutable bitmask states,
dominance normalization, fixed edge/nonedge rows, nonnegative integer linear
budgets, cached Ramsey bounds and completion counts, and an explicit DAG format.
Imports perform no search. The fixed connected-`A` initializer labels the root0,
`A=1..18`, and `B=19..42`; it checks that small supplied neighborhood and builds
the degree-budget state. It does not execute order43 recursion. Optional
cross-count intervals are caller-supplied branch assumptions. The optional
`B` edge interval144..160 is disabled by default and retains its published census
premise. Maximum-density root selection is not encoded: the initialized broader
class contains every selected root with the supplied `A`.
