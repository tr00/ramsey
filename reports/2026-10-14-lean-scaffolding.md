## Conventions adopted

- Mathlib v4.35.0 is built with the Lean module system: source files start
  with `module`, then imports, then the module docstring. Importing `Mathlib`
  from a file without `module` produces a warning under Lean 4.35.0; both
  scaffold files use `module`. Future files should follow the same shape
  (see any `Mathlib/**.lean` header).
- `lake-manifest.json` stays committed so builds are reproducible; `lake
  update` is run only when intentionally moving the Mathlib pin.
